# MSM

Инструмент для автоматического стресс-тестирования решений олимпиадных задач по программированию. Позволяет находить ошибки путём сравнения вывода вашего решения с эталонной программой на большом количестве случайных тестов.

## Возможности

- **Два режима тестирования:**
  - *Brute Force* — сравнение ответов решения и эталона на тестах от генератора
  - *Interactive* — тестирование интерактивных задач через взаимодействие с программой-интерактором
- **Поддержка языков:** C++, Python, Java, Pascal, Rust, Kotlin, D, JavaScript, Ruby
- **Настройка параметров:** количество тестов, таймаут выполнения, остановка при первой ошибке
- **Сохранение конфигураций** в JSON для повторного использования
- **Тёмная и светлая темы** оформления
- **Детальное логирование:** отдельные вкладки для общего лога, проваленных тестов и ошибок
- **Прогресс-бар** выполнения тестов
